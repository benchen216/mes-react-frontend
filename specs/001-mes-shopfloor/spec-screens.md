# 規格畫面欄位清單

來源: [spec.md](spec.md)。用來對畫面該出現什麼，不是功能清單。文中的 R-xx 規則編號對應 spec.md 附錄 B，編號未因遷移而改動。

讀法:
- 固定區: 所有站都有，版面不要因產線改掉。
- 表單區: 按工序設定長出來，產線 A / B 欄位不同。
- 規格未寫: 情境沒給欄位或沒給版面，畫之前要先定。

## 2. 工位終端：固定骨架

生產站與品檢站同一套骨架。差別只在按鈕與按下完成 / 判定後的表單。

### 2.1 頁首（站點鎖定）

| 顯示 | 型別 | 說明 |
| --- | --- | --- |
| 站點名稱 | 唯讀 | 例: 沖壓線、沖壓品檢站。畫面預設就停在這一站 |
| 本關工序 | 唯讀 | 例: 薄板沖壓 |
| 作業員 / 角色 | 唯讀 | 例: 王沖壓。不現場輸入工號 |
| 系統回話 | 唯讀文案 | 每次開始 / 完成 / 被擋後更新 |

### 2.2 待辦清單（畫面上半）

一列一張（或一批）工單。規格示範通常只有一行。

| 欄 | 型別 | 例 |
| --- | --- | --- |
| 工單號 | 文字 | MO-FR-27-005 |
| 產品 | 文字 | 金屬前框 |
| 本關工序 | 文字 | 薄板沖壓 |
| 數量 | 數字 + 單位 | 10,000 個 |
| 狀態 | 標籤 | 可開始 / 進行中 / 還不能開始 / 可重做 |

狀態字不要自創。看板對照見第 9 節。

### 2.3 工序卡（畫面下半）

| 欄 | 型別 | 例 |
| --- | --- | --- |
| 本關 | 唯讀 | 薄板沖壓 |
| 上一關 | 唯讀 | 無 / 沖壓品檢 |
| 下一關 | 唯讀 | 沖壓品檢 / 無（工單結束） |
| 狀態 | 唯讀 | 尚未開始 / 進行中 / 已完成 / 不合格 / 可重做 / 還不能開始 |
| 作業員 | 唯讀 | 開始後才出現。例: 王沖壓 |
| 開始時間 | 唯讀時間 | 開始後才出現。例: 08:12:30 |

### 2.4 按鈕

生產模式:

| 按鈕 | 何時可按 | 何時灰 |
| --- | --- | --- |
| 開始 | 狀態 = 可開始 或 可重做 | 進行中、已完成、還不能開始 |
| 完成 | 狀態 = 進行中 | 尚未開始、還不能開始 |

品檢模式: 沒有「完成」。開始進入判定後，改為:

| 按鈕 | 說明 |
| --- | --- |
| 合格 | 帶出判定表單，判定預設合格 |
| 不合格 | 帶出判定表單，並多出不良代碼、退回工序等欄 |

規格另有判定值「部分不合格」（情境四）。按鈕要不要第三顆、或合格/不合格進去再選，規格沒寫死，見第 12 節。

還不能開始時，規格示範仍看得到「開始」，按下後被擋，不是把按鈕拿掉。

### 2.5 系統回話（頁尾）

規格出現過的文案，畫面要預留夠大的一句話區域:

| 時機 | 文案 |
| --- | --- |
| 開始成功 | 本關進行中。作業員：王沖壓。開始：08:12:30 |
| 生產完成 | 本關已完成。下一關是「沖壓品檢」，由「沖壓品檢站」開始。 |
| 品檢合格（非末站） | 沖壓品檢合格。下一關是「雷射焊接」。工單尚未結束。 |
| 末站合格 | 成品品檢合格。工單已結束。 |
| 跳站 | 還不能開始。需先完成「沖壓品檢」。 |
| 料件短缺 | 還不能開始。料件 FR-27-BZ-A 可用量 1,800，需求 2,000，短缺 200。 |
| 退回 | 判定不合格。工單不能結束。請退回「薄板沖壓」重做。焊接尚未開始。 |
| 末站全數報廢 | 報廢 9,700。工單 MO-FR-27-005 結案，完工數量 0，報廢 9,700。 |
| 欄位超範圍 | 氬氣流量 25 超出有效範圍 12 ~ 20。 |
| 覆寫量測 | 規格要求必須填理由，完整文案未寫。 |

未填必填: 完成無法送出（R-07）。數量分流不對: 畫面上標紅，送不出去（R-15）。

## 3. 生產站回報表單（按完成後）

表單內容來自該站設定，不是寫死。下面是規格有舉例的欄。

### 3.1 薄板沖壓（沖壓線）

| 欄位 | 型別 | 必填 | 驗證 / 選項 | 示範值 |
| --- | --- | --- | --- | --- |
| 實際沖壓數 | 數字 | 是 | 規格未寫上下限 | 10,000 |
| 模具編號 | 單選 | 是 | 示範 MD-FR27-02、MD-FR27-05 | MD-FR27-02 |
| 料捲批號 | 文字 | 是 | 無 | RC-20260815-A |
| 備註 | 文字 | 否 | 可空白 | （空白） |

此站「是否回報數量」= 是。

### 3.2 雷射焊接（雷射焊接站）

| 欄位 | 型別 | 必填 | 驗證 / 選項 | 說明 |
| --- | --- | --- | --- | --- |
| 數量回報 | 數字 | 是 | 規格只標「回報數量」，欄名未寫死 | 與沖壓的「實際沖壓數」同類 |
| 氬氣流量 (L/min) | 數字 | 是 | 12 ~ 20 | 情境六才新增。設定前已完成的紀錄顯示「—」 |

焊接站其餘欄位規格沒給。

### 3.3 清洗（清洗站）

是否回報數量 = 否。完成後要不要跳出表單，規格沒給任何欄。

### 3.4 前框上料組裝（組裝一線）

| 欄位 | 型別 | 必填 | 驗證 / 選項 |
| --- | --- | --- | --- |
| 完成台數 | 數字 | 是 | 規格未寫上下限 |
| 前框批號 | 單選 | 是 | 自動帶入可用批號（來自產線 A 成品） |
| 面板批號 | 文字 | 是 | 無 |

料件不夠時，按開始就被擋，還進不了這張表。

### 3.5 電控模組安裝（組裝二線）

規格沒給回報欄位。骨架仍是開始 / 完成。

### 3.6 包裝入庫（包裝線）

規格只寫「完工即入庫」，沒給回報欄位。骨架仍是開始 / 完成。

## 4. 品檢站判定表單

品檢沒有「完成」，按合格 / 不合格（或送出判定）才填這張。

### 4.1 所有品檢站都會用到的分流欄

| 欄位 | 型別 | 必填 | 條件 | 示範 |
| --- | --- | --- | --- | --- |
| 判定 | 單選 | 是 | 選項見第 10 節 | 合格 / 不合格 / 部分不合格 |
| 合格數 | 數字 | 是 | 與重工數、報廢數加總 = 送檢數 | 10,000 / 0 / 9,200 |
| 重工數 | 數字 | 是 | 同上 | 0 / 10,000 / 500 |
| 報廢數 | 數字 | 是 | 同上 | 0 / 300 / 9,700 |
| 不良代碼 | 多選 | 不合格時必填 | 部分不合格也要填（情境四） | DEF-FLAT、DEF-BURR、DEF-COATING |
| 退回工序 | 單選 | 判定不合格時必填 | 可選範圍: 本站之前的所有生產工序 | 薄板沖壓 |
| 報廢原因 | 單選（代碼） | 報廢數 > 0 時必填 | 示範 SCR-UNREPAIRABLE | SCR-UNREPAIRABLE |

判定選項規格出現過三種: 合格、不合格、部分不合格。

加總規則: 合格數 + 重工數 + 報廢數 = 送檢數。不相等則該三格標紅，不能送出。

### 4.2 沖壓品檢（沖壓品檢站）

在 4.1 之外再加:

| 欄位 | 型別 | 必填 | 驗證 | 示範 |
| --- | --- | --- | --- | --- |
| 抽檢數 | 數字 | 是 | 規格未寫上下限 | 200 |
| 平面度 (mm) | 數字 | 是 | 上限 0.35 | 合格 0.21 / 0.19；不合格 0.52 |

不合格時多出: 不良代碼、退回工序。報廢數 > 0 時多出: 報廢原因。

### 4.3 成品品檢：全數報廢示範值

| 欄位 | 值 |
| --- | --- |
| 判定 | 不合格 |
| 合格數 | 0 |
| 重工數 | 0 |
| 報廢數 | 9,700 |
| 不良代碼 | DEF-COATING |
| 報廢原因 | SCR-UNREPAIRABLE |

最終品檢、重工數 = 0、報廢數 = 送檢數時，判定當場生效並結案，不經線長審核。


### 4.4 功能測試（測試房）

品檢骨架 + 治具帶值。人幾乎不用打字，但可覆寫。

| 欄位 | 型別 | 必填 | 來源 | 驗證 |
| --- | --- | --- | --- | --- |
| 測試報告編號 | 文字 | 是 | 治具自動寫入 | 無 |
| 亮度 (cd/m²) | 數字 | 是 | 治具自動寫入 | 350–450 |
| 色差 ΔE | 數字 | 是 | 治具自動寫入 | 上限 3.0 |
| 判定 | 單選 | 是 | 治具自動寫入，人可覆寫 | 超範圍時系統先帶「不合格」 |
| 覆寫理由 | 文字 | 覆寫超出範圍的值、或把不合格改合格時必填 | 人填 | 規格未給欄名，規則在 R-08、7.2 |

合格數 / 重工數 / 報廢數這站規格沒寫。若走品檢模式，建議沿用 4.1；畫之前要確認。

### 4.5 外觀檢驗（目檢站）

| 欄位 | 型別 | 必填 | 條件 |
| --- | --- | --- | --- |
| 判定 | 單選 | 是 | 合格 / 不合格（是否含部分不合格未寫） |
| 缺陷代碼 | 多選 | 不合格時必填 | 代碼清單由管理員維護 |
| 缺陷照片 | 照片，可多張 | 不合格時必填 | 終端相機直拍，綁這一次檢驗紀錄 |
| 合格數 | 數字 | 是 | 分流加總規則同 4.1 |
| 重工數 | 數字 | 是 | 同上 |
| 報廢數 | 數字 | 是 | 同上 |

報廢原因、退回工序這站規格沒再寫。若判定不合格或報廢數 > 0，建議沿用 4.1 條件必填。

## 6. 追溯

輸入工單號，一頁列出所有站、所有次數。退回不覆蓋，第 N 次累加。

| 欄 | 型別 | 例 |
| --- | --- | --- |
| 工單號（查詢） | 文字輸入 | MO-FR-27-005 |
| 工序 | 唯讀 | 薄板沖壓 |
| 次數 | 唯讀 | 第 1 次 / 第 2 次 |
| 時段 | 唯讀 | 08:12–09:40 |
| 人 | 唯讀 | 王沖壓 |
| 該次紀錄摘要 | 唯讀 | 模具、料捲、平面度、不良代碼… 依該次欄位版本 |
| 結果 | 唯讀 | 完成 / 合格 / 不合格 |

規格要能在三十秒內指到: 哪一批料、哪一副模具、哪一個人、哪一個時段。動態欄位（如氬氣流量）設定後也要進這張表；設定前的舊列該格顯示「—」。

權限: 作業員只看本站；檢驗員 / 線長 / 管理員看全線。

## 7. 系統設定：記錄欄位

路徑: 系統設定 → 記錄欄位 → 選工序 → 新增 / 修改 / 停用。

新增一欄要填的六格（刻意收斂，三分鐘內填完）:

| 設定項 | 型別 | 必填 | 規則 |
| --- | --- | --- | --- |
| 欄位代碼 | 文字 | 是 | 建立後不可改。報表欄名用這個 |
| 顯示名稱 | 文字 | 是 | 可隨時改，不影響歷史 |
| 資料型別 | 單選 | 是 | 數字 / 文字 / 單選 / 多選 / 是否 / 日期 / 照片 |
| 是否必填 | 是否或條件 | 是 | 可設條件必填，例如僅不合格時必填 |
| 適用工序 | 多選 | 是 | 這個欄位出現在哪一站 |
| 驗證範圍 | 依型別 | 視型別 | 數字: 上下限。單選 / 多選: 選項清單 |

示範（氬氣流量）:

| 設定項 | 值 |
| --- | --- |
| 欄位代碼 | argon_flow |
| 顯示名稱 | 氬氣流量 (L/min) |
| 資料型別 | 數字 |
| 是否必填 | 是 |
| 適用工序 | 雷射焊接 |
| 有效範圍 | 12 ~ 20 |

按鈕: 儲存。沒有刪除，只有停用。

同一套設定畫面還要能改（8.5、9.5）:

| 項目 | 畫面含義 |
| --- | --- |
| 不良代碼清單 | 代碼 + 顯示名稱。例 DEF-FLAT 平面度超標 |
| 報廢原因代碼清單 | 例 SCR-UNREPAIRABLE |
| 站點與作業員對應 | 哪一站預設誰 |

## 10. 欄位出現條件（實作時最容易漏）

1. 不良代碼: 判定為不合格或部分不合格才必填，建議同時才顯示。
2. 退回工序: 判定不合格才必填。可選 = 本站之前的生產工序，不含品檢站自己。
3. 報廢原因: 報廢數 > 0 才必填，建議同時才顯示。
4. 缺陷照片 / 缺陷代碼: 外觀檢驗、不合格時必填。
5. 覆寫理由: 治具值超範圍被改、或判定從不合格覆寫成合格時必填。
6. 氬氣流量: 只出現在雷射焊接、且該欄已啟用之後的新紀錄。
7. 開始時間 / 作業員: 按開始之後才寫上工序卡，不可事後改。
8. 分流三格: 任何品檢送出都要驗加總；不對就標紅。

## 11. 規格沒寫死、畫面前要確認

這些不是「可以省略」，是規格沒給版面或欄名，不要默默發明一版卻當成規格。

1. 電控模組安裝、清洗、包裝入庫的完工表單有哪些欄。
2. 雷射焊接在加氬氣流量之前，除數量外還有沒有別欄。
3. 「部分不合格」是第三顆按鈕，還是不合格表單裡的判定選項。
4. 工單詳情頁（線長主畫面之一）有哪些欄。
5. 覆寫理由的欄名與放在表單哪裡。
6. 功能測試要不要合格數 / 重工數 / 報廢數。
