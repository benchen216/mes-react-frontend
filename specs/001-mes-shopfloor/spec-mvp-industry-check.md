# 展示用 MVP：請業界核對

這份給現場、品保、生管、或導入過 MES 的人看。不是規格全文。規格在 [spec.md](spec.md)。

請你幫我們打槍：這些情境拿去對客戶螢幕 demo，會不會被現場的人覺得假、或一問就穿幫。

預設閱讀 15 分鐘。每題勾「現場就是這樣 / 有這件事但不該進第一版 / 我們現場不是這樣」。最後請寫一句：這組情境可不可以當展示 MVP。

---

## 0. 這版 MVP 要證明什麼

只證明三件事。不是排程系統，不是倉退系統，不是 ERP。

1. 作業員在工位終端只按「開始 / 完成」。不用選工單、不用記今天做哪張。
2. 跳站當下按不下去。不是事後稽核才發現。
3. 品檢退回或報廢之後，舊紀錄留得住。出事能在一頁看到哪批料、哪副模具、哪個人、哪個時段。

若這三件對你們現場不成立，後面情境都不必看。

---

## 1. 用詞先對一下

規格用「重工 / 報廢」。現場常講「退貨 / 銷毀 / 退料」。請先確認有沒有講同一件事。

| 規格用詞 | 規格意思 | 請你填：你們現場怎麼叫 | 是不是同一件事 |
| --- | --- | --- | --- |
| 合格數 | 這批可以往下一站 | | 是 / 否 / 部分是 |
| 重工數 | 退回指定的前站重做 | | 是 / 否 / 部分是 |
| 報廢數 | 就地報廢，不再流動，成本仍掛這張工單 | | 是 / 否 / 部分是 |
| 退回工序 | 不合格時指定退到哪一站 | | 是 / 否 / 部分是 |

若你們的「退貨」是退回倉庫、退供應商、或客退，規格這版沒做。請在第 6 節直接寫「第一版不要講退貨」。

---

## 2. 建議拿去展示的情境

產線背景用金屬前框沖焊線，五站：

薄板沖壓 → 沖壓品檢 → 雷射焊接 → 清洗 → 成品品檢

工單 `MO-FR-27-005`，10,000 個。作業員不選單。每一站有自己的待辦，做完自動出現在下一站。

### 必演（沒這三段就不要稱展示 MVP）

情境 A：整批一次過

王沖壓按開始、做完 10,000、填實際數 / 模具 / 料捲、按完成。李檢驗在品檢站待辦上看到這張單（沒人通知他），判定合格。後面焊接、清洗、成品品檢同樣走完，工單結束。

請核對:

- [ ] 現場就是「整關做完再轉下一站」，不是生產中途先轉 3,000 個
- [ ] 品檢合格後，下一站自己看到待辦，這件事值得演
- [ ] 終端鎖定在這一站、不選工單，現場接受
- [ ] 不接受，我們現場一定要自己挑單

情境 B：搶跑被擋

沖壓剛完、品檢還沒做。陳焊接在焊接站按開始。系統說：還不能開始，需先完成沖壓品檢。工單狀態不變。

請核對:

- [ ] 現場最在意的就是「系統控不控得住跳站」，這段該演
- [ ] 我們現場允許暖機、允許先做後補單，這段會被吐槽
- [ ] 擋下之後只回話、不寫紀錄，這樣對

情境 C：整批退回重做

品檢平面度超標，判定不合格，重工數 10,000，退回薄板沖壓。後段焊接維持「還不能開始」。王沖壓換模具做第 2 次。追溯上看得到第 1 次與第 2 次兩筆，不覆蓋。

請核對:

- [ ] 整批退回前站重做，現場常發生，該演
- [ ] 退回一定指定退到哪一站，不能只寫「不合格」
- [ ] 舊紀錄必須留，這是買 MES 的理由
- [ ] 我們現場是整批退倉，不是退回前站，這段會演錯

### 加演（有時間再演；第一版可以只口頭講）

情境 D：一部分過、一部分重做、一部分報廢

10,000 拆成 9,200 合格往焊接、500 退回沖壓、300 就地報廢。主批不必等重工批。加總不對就送不出。

請核對:

- [ ] 現場品檢就是這樣拆數量，該進第一版展示
- [ ] 有這件事，但第一版演整批退回就夠，拆數量太容易被追問倉帳
- [ ] 合格那批先走、重工後補，現場真的這樣跑產能
- [ ] 我們現場一定整批卡住等重工結束，規格這條會挨打


情境 F：第二條組裝線，同一套畫面、不同表單

組裝站仍是待辦 + 開始 / 完成。差別只在完成後的欄位（前框批號、治具亮度、目檢拍照）。

請核對:

- [ ] 「換一條線不用改程式」這句，客戶會買單，該演
- [ ] 第一版只演一條沖焊線就夠，第二條線留到第二次會議
- [ ] 治具自動帶值、目檢拍照，沒接真機台就不要演，會被問介接

情境 G：品保自己加一個欄位

管理員在設定裡幫焊接站加上「氬氣流量」，三分鐘、不停機。下一張完工表單就出現。舊紀錄該格顯示「—」，不追認為缺漏。

請核對:

- [ ] 客戶一定會問「以後加欄位要不要花錢」，該演
- [ ] 第一版口頭講即可，不必做成可操作畫面
- [ ] 我們現場加欄位一定走 IT / 供應商，這段承諾太滿

## 3. 展示時故意不演

下面這些現場一定會問。請告訴我們：是「先承認不做」就好，還是「沒演這個就不能稱 MVP」。

| 不做的事 | 規格怎麼寫 | 請勾 |
| --- | --- | --- |
| 同一站多張工單，作業員自己選要做哪張 | 示範永遠一行，系統已決定這一站做哪張 | 可先不演 / 不演就不能展示 |
| 排程、插單、優先序、產能負載 | 本版範圍外 | 可先不演 / 不演就不能展示 |
| 生產站分批報工（先轉 3,000，其餘留本站） | 沒寫。只允許品檢把數量拆開 | 可先不演 / 不演就不能展示 |
| 退貨給倉庫 / 供應商 / 客戶 | 沒有退貨單 | 可先不演 / 不演就不能展示 |
| 銷毀作業、銷毀單 | 只有就地報廢，成本仍掛工單 | 可先不演 / 不演就不能展示 |
| 換班暫停、待料中途停錶 | 一開始就計到完成 | 可先不演 / 不演就不能展示 |
| 作業員改已送出的回報 | 要改只能由線長退回 | 可先不演 / 不演就不能展示 |
| 離線 | 不涵蓋 | 可先不演 / 不演就不能展示 |
| ERP / 治具 / 量測儀真介接 | 治具帶值是目標行為，本版可模擬 | 可先不演 / 不演就不能展示 |

## 4. 請你直接回答的問題

用現場的話答即可。不要幫我們圓。

品檢

1. 你們品檢是「整批合格 / 整批退回」，還是「同一批可以拆成過 / 重做 / 報廢」？
2. 「退貨」在你們口中，是退回前站、退倉、還是退供應商？展示時能不能改口說重工、報廢？
3. 報廢之後，現場下一步是就地報廢、開銷毀單、還是退倉待處理？第一版只做到「數量不再往下流」可不可以？
4. 合格的那一批，可不可以不等重工、先過下一站？

轉關

5. 生產站是不是「這關全部做完才轉下一站」？有沒有「做多少轉多少」？
6. 下一站待辦自己出現、不必跑單，現場聽了會點頭還是會問「那誰決定先做哪張」？

控管

7. 跳站該不該當下擋住？有沒有合法的「先做後補」？
9. 追溯留每一次重做、不覆蓋，這件事值不值得當 demo 高潮？

展示範圍

10. 第一次對客戶螢幕，三段必演夠不夠？還是沒有「拆數量」或「第二條線」會被認為功能太少？
11. 用監視器前框這條故事，金屬加工以外的人聽不聽得懂？要不要改成你們更熟的產品？

## 6. 我們已知的洞，請順便打槍

不求這次補完規格，只要告訴我們「展示前一定要先講清楚」還是「沒關係」。

1. 清洗、電控、包裝幾乎沒有回報欄。展示時只演沖壓 + 品檢 + 焊接可不可以。
2. 「部分不合格」是第三顆按鈕，還是合格/不合格進去再拆數量，規格沒定。
3. 同一站同時兩張單都輪到了，誰先做，規格沒寫。展示維持一張單。
4. 報廢原因代碼沒有中文顯示名。
